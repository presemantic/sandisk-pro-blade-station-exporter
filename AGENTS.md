# PRO-BLADE Station exporter

Linux Go exporter for SanDisk PRO-BLADE STATION USB HID 4791:2064. Keep device access in internal/hid, validated telemetry protocol in internal/protocol, hotplug discovery in internal/device and collection/Prometheus in internal/exporter. Cooling control is explicitly authorized as an opt-in component in internal/control. The only permitted actuator is verified report-6 manual PWM/automatic restore on firmware 2.0.1.2. Keep the report-8 GET allowlist separate; never add thermal-table writes, bootloader entry, firmware updates or other configuration writes. Control must use explicit hashed station/disk mappings, fresh local SMART data, a renewed lease, measured RPM validation and an independent watchdog. Source control settings through Helm, reapply every cycle and after restarts; label commanded PWM honestly rather than claiming hardware PWM readback.

Support multiple stations without assuming hidraw numbers or physical bay order. Never export raw serial numbers; use a stable SHA-256-derived station ID and optional user aliases. Poll hardware on a bounded background schedule, never from HTTP requests. An unavailable device must lose sensor values rather than replay stale values. Preserve errors and freshness metrics. Protocol support is explicit and initially covers firmware 2.0.1.2; unsupported firmware gets identity/health only.

No host scripts or systemd units. Build/test/publish the image through GitHub Actions. The reusable Helm chart is owned by presemantic/charts at v2/sandisk-pro-blade-station-exporter; Szew values and Argo registration are owned by presemantic/deploy and presemantic/argo-self. Run go test -race ./..., go vet ./..., Linux amd64/arm64 cross-builds and protocol fuzz checks for protocol changes.
